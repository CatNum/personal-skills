# 术语表细则

适用于统一某个产品、功能或设计领域的名称与含义；同时遵循主 `SKILL.md` 的通用格式。

## 条目与组织

- `## 重点` 概括术语表的范围及最关键的定义边界，不重复列出所有词条。
- 可按主题建立正文主节，并在需要时用下级标题放置词条。每个词条按已有信息写标准名称、简明定义、适用范围、易混淆词、相关术语和来源；缺失字段不强加。
- 同一功能的产品文档与设计文档引用同一词条；ROADMAP 提及该功能时沿用标准名称。不要在各文档中维护互相冲突的定义。
- 来源对同一词语给出不同含义时，记录差异并标为待确认，不自行合并。没有现成术语定义时，不凭空创建权威定义或链接。

## 场景检查

产品文档称“任务”、设计文档称“事项”，但来源未说明是否同义时，标记待确认；不要擅自统一为其中一个词。
