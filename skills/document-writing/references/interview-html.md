# 面试复盘 HTML 输出

## 重点

- **适用范围**：只在用户要求面试复盘 HTML 或双格式时读取。
- **内容一致**：HTML 与 Markdown 使用同一分析结果，仅呈现方式不同。

## 一、渲染与交付

先遵循 [面试复盘规则](interview-review.md) 完成分析或保留既有分析，
再按 [HTML 模板](../assets/interview-review.html) 组织独立 HTML 文件。
直接交付 HTML 时无需先生成 Markdown 文件。

使用一个 `h1`、紧随其后的重点 `h2`、连续的正文层级，
并用 `p`、`ul`、`ol`、`strong`、`code`、`blockquote` 和链接表达语义。
这些元素依次承载段落、无序列表、有序步骤、强调、精确技术文本和原文引用。
逐题标题使用疑问句还原面试官问题并以问号结尾；
题目及短板小标题的编号与正文所属章节一致。
按实际内容删去不适用模板字段和空章节；模板占位符不能进入成品。

插入转写稿、题干、代码等文字时进行 HTML 转义，
不把材料中的标签或脚本当作可执行 HTML。
长文本自然折行；代码和表格避免撑宽整个页面。
沿用模板的响应式布局，不仅靠颜色区分评分等级。

无需为普通面试复盘强加 Mermaid；确需图示时，
提供图意说明，并确保 HTML 中能够实际查看图或完整图源，
不把 Markdown 围栏语法当成已渲染图形。

## 二、自检

检查 HTML 结构、标题顺序、逐题标题的疑问句表达、字段顺序、
长文本换行和窄窗口布局。
双格式对照题目、评分、证据、短板与答案，避免两次独立生成造成差异。
只输出用户请求的格式，不额外生成另一种文件。
