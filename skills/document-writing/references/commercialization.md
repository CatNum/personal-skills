# 商业化文档细则

适用于独立记录产品商业模式、收费与计费策略的文档；
同时遵循主 `SKILL.md` 的通用格式。

## 内容与组织

- `## 重点` 提炼主要商业模式、收费规则和关键约束。
- 按已有材料选择商业目标、收费对象、套餐与权益、
  定价、计费周期、试用与退款规则等章节；
  内容较少时合并章节，有依据时用表格比较套餐。
- 已有价格、时间、权益和商业假设保持原有确定程度；
  缺失内容按实际缺口处理，不推测收入、成本或价格。
- 文档独立于 PRD，并链接受这些规则影响的产品文档。
  商业化文档维护商业策略与收费规则，
  PRD 描述对应功能行为及用户可见的限制。

## 场景检查

材料同时包含“用户可以创建清单”和不同套餐的价格时，
本文件记录套餐、价格及相关收费规则，
并链接描述清单功能的 PRD。
